Install Mac OS X — follow these steps in the Mac screen
  1. Choose your language and click the arrow. When Install Mac OS X appears, choose Utilities → Disk Utility… from the Mac’s own menu bar.
  2. In Disk Utility select 100.0 GB QEMU HARDDISK, click the Erase tab, give the disk a name, click Erase and confirm: it gets the GUID partition table an Intel Mac starts from. Then choose Disk Utility → Quit Disk Utility.
  3. In the Installer click Continue, agree to the license, select your new disk, click Continue, then Install.
  4. Copying takes a few minutes. At its end the Installer restarts the Mac and this screen closes: click Installation finished — start my Mac below. Setup Assistant then asks to identify the keyboard: click OK and press the keys it shows.

Disk Utility’s Erase applies to this Mac’s virtual hard disk. Use it only during this first installation.

Your Mac is shut down. Its files are saved. Click Start Mac to return to the desktop.
