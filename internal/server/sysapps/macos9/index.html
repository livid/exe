Install Mac OS 9 — follow these steps in the Mac screen
  1. Wait for the installer desktop. Close the Read Me with File → Quit. In Drive Setup (or open it from the CD’s Applications folder), select the <not initialized> hard disk, click Initialize…, then Initialize. Quit Drive Setup when it finishes.
  2. Open the MacOS9Lives CD, then Apple Software Restore. Keep the supplied image and the new hard disk selected. Click Restore, then confirm OK.
  3. Wait for “The volume was successfully restored”. Quit Restore. Choose Special → Shut Down from the Mac’s own menu bar.
  4. Once the Mac has stopped, click Installation finished — start my Mac below. On its first hard-disk boot, quit the Mac OS Setup Assistant if you do not need it.

The installer’s Erase option applies to this Mac’s virtual hard disk. Use it only during this first installation.

Your Mac is shut down. Its files are saved. Click Start Mac to return to the desktop.
